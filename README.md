# Usagi Desktop

อุซางิตัวจิ๋วบนเดสก์ท็อป Windows พร้อมเมนูไทย เสียงตัวละคร ตัวจับเวลาและการแจ้งเตือน

## ดาวน์โหลด

[เปิดหน้าดาวน์โหลดรุ่นล่าสุด](https://github.com/nickvirgofx-dev/usagi-desktop-releases/releases/latest) แล้วเลือกไฟล์ **UsagiDesktop-Setup-…-x64.exe**

ติดตั้งรุ่น 0.2.6 ขึ้นไปครั้งเดียว จากนั้นรับแพตช์ครั้งถัดไปในตัวแอป: คลิกขวา Usagi → ตั้งเวลาและแจ้งเตือน → ตั้งค่าแอป → อัปเดตโปรแกรม

Usagi ตรวจอัปเดตและดาวน์โหลดเบื้องหลัง แล้วแจ้งให้กด **อัปเดตและเปิดใหม่** เมื่อพร้อม มีสวิตช์ปิดระบบอัตโนมัติได้ Windows อาจขอสิทธิ์ผู้ดูแลระบบขณะติดตั้ง

รุ่น 0.2.5 และเก่ากว่ายังไม่มีระบบอัปเดตในแอป ต้องติดตั้งรุ่นที่รองรับหนึ่งครั้ง

## การใช้งาน

- ลาก Usagi ไปวางบนจอ คลิกขวาเพื่อตั้งขนาด เสียง เวลาและการแจ้งเตือน
- ค่าเริ่มต้นตัวเล็ก เปิดพร้อม Windows; ปิด Startup ได้ในตั้งค่าแอป
- ตั้งเตือนดื่มน้ำ พักสายตา นับถอยหลัง และกำหนดความถี่การพูดเอง
- ตั้งค่าผู้ใช้เก็บในเครื่องและคงไว้ขณะอัปเดต

Repository นี้มีเฉพาะไฟล์แจกจ่าย ข้อมูลอัปเดตและบันทึกเวอร์ชัน
